# 生鲜供应链销量预测：营销类特征 EDA (探索性数据分析) 报告

## 1. 分析背景与目标

在生鲜零售场景中，促销与节假日通常是拉动销量的核心因素。为了探究这三者的内在联系及其对销量预测模型的潜在影响，我们从 `FreshRetailNet-50K` 数据集中随机抽取了 10 万条数据，专门针对以下三个营销类特征进行了相关性分析与散点图可视化：
1. `discount`：折扣力度（连续变量，0~1之间，1.0 代表不打折）。
2. `holiday_flag`：节假日标志（二值变量，0=工作日，1=节假日）。
3. `activity_flag`：营销活动标志（二值变量，0=无活动，1=有活动）。

---

## 2. 相关系数 (Pearson Correlation) 分析

通过计算这三个特征的皮尔逊相关系数（R值），我们得到了如下的热力图矩阵：

| 特征对 | R 值 | 相关性强度 | 业务洞察 |
| :--- | :---: | :---: | :--- |
| `activity_flag` & `discount` | **-0.674** | **强负相关** | 当平台开启营销活动（=1）时，商品价格必然伴随显著的打折（折扣值变小）。这两者在业务逻辑上高度绑定，在模型中可能存在一定的多重共线性。 |
| `holiday_flag` & `discount` | -0.012 | 极弱相关 | 生鲜折扣并不严重依赖节假日。由于生鲜属于高频且易腐商品，晚间清仓、日常秒杀等常规打折动作极其频繁。 |
| `holiday_flag` & `activity_flag`| 0.021 | 极弱相关 | 平台搞营销活动的时间分布相对均匀，并非“只有节假日才搞活动”。 |

---

## 3. 散点图 (Scatter Plot) 分布特征

为了克服二值变量（0 和 1）在散点图中严重重叠的问题，我们在绘图时对 `holiday_flag` 和 `activity_flag` 引入了微小的随机抖动（Jitter），从而清晰地展现了 10 万个样本的数据密度分布：

### 3.1 折扣 vs 节假日 (Discount vs Holiday Flag)
- **数据表现**：无论是在 X=0（工作日）还是 X=1（节假日）的两侧，Y轴（折扣值）上的散点密度分布几乎一致：顶部密（不打折），中下部疏（打折）。
- **结论**：**“平时也会打折，节假日也未必大打折”**。生鲜的折扣策略更多受保质期、库存压力驱动，而非日历节假日。

### 3.2 折扣 vs 营销活动 (Discount vs Activity Flag)
- **数据表现**：
  - 无活动（X=0）时，绝大多数样本点极其密集地挤在 Y=1.0（不打折）这条水平线上。
  - 有活动（X=1）时，大量样本点散布在 Y=0.5 到 Y=0.9 的区间内。
- **结论**：**“有活动必打折”**。这直观地印证了 -0.674 的强负相关性，说明 `activity_flag` 是触发 `discount` 下降的核心开关。

### 3.3 营销活动 vs 节假日 (Activity Flag vs Holiday Flag)
- **数据表现**：在由 (0,0), (0,1), (1,0), (1,1) 构成的四个象限集群中，左下角（平时且无活动）和右下角（平时且有活动）的数据点最为密集。
- **结论**：**“营销活动并非节假日的专属”**。叮咚买菜的营销策略呈现出常态化、高频化的特征，靠日常的活动拉新促活，而非死等大促节点。

---

## 4. 对预测模型（校赛）的指导意义

1. **特征交叉组合（Feature Crossing）**：鉴于 `discount` 和 `activity_flag` 存在强烈的绑定关系（-0.674），在构建树模型（如 LightGBM/XGBoost）时，可以考虑构造一个交叉特征（如 `discount * activity_flag`），以帮助模型更直接地捕捉到“活动期间的真实折扣力度”这一强刺激信号。
2. **权重认知**：在生鲜销量预测任务中，**折扣和日常活动是拉动销量的绝对主力**，而“节假日”这一传统零售中的黄金特征，在生鲜高频消费场景下的权重相对较弱。如果模型在训练后赋予了 `holiday_flag` 过高的重要性，则需警惕是否发生了过拟合。


---

## 5. 高度耦合特征（R = -0.674）的进阶处理策略

针对 `discount`（折扣）与 `activity_flag`（营销活动）之间高达 -0.674 的强相关性，直接将两者平行输入模型会导致信息冗余（多重共线性）或模型对单一特征的过度依赖。

为此，我们设计了两种应对方案，分别适用于传统机器学习（追求极强解释性）与深度学习（追求高级表征能力）：

### 方案 A：业务直觉驱动的“条件特征构造”（Conditional Feature Engineering）
- **实现方式**：绝不能直接相乘！正确的构造公式为 `real_activity_discount = np.where(activity_flag == 1, discount, 1.0)`，即 `discount * activity_flag + 1.0 * (1 - activity_flag)`。
- **业务解释性与避坑**：
  - **直接相乘的灾难**：如果直接相乘，无活动（flag=0）时结果为 0，在折扣语境下 0 代表“免费/0元购”，这会让模型产生极其严重的误判（以为平时没活动的东西都是免费送的）。
  - **正确的逻辑**：当 `activity_flag = 0`（无活动）时，强制该特征等于 **1.0**（代表原价/不打折）。
  - 当 `activity_flag = 1`（有活动）时，取真实的折扣率（如 0.8）。
- **模型意义**：该方法向模型传递了一个极强的业务信号——**“只有官方营销活动背书下的打折，才是真正刺激销量爆发的有效打折”**。平时因临期清仓导致的打折（虽有 discount 但无 activity_flag），其对销量的拉动作用会被该特征有效隔离。此方法在 LightGBM / XGBoost 等树模型中表现极佳。

### 方案 B：深度学习视角的“自编码器特征解耦”（Disentanglement via AutoEncoder）
- **实现思路**：面对 70% 的信息重叠和 30% 的特异性差异，若使用神经网络提取深层表征，模型极易将“价格因素”与“流量因素”混为一谈。为此，我们引入带有**可导正则化约束**的自编码器进行特征解耦。
- **技术实现（可导 Loss）**：
  在自编码器的重构 Loss 基础之上，加入针对隐藏表征 $Z_1$（代表纯粹价格波动）和 $Z_2$（代表活动曝光流量）的惩罚项：
  1. **Pearson 惩罚（Pearson Penalty）**：利用皮尔逊相关系数公式（加极小值 $\epsilon$ 防止分母为 0 导致梯度爆炸）作为惩罚项，强制 $Z_1$ 与 $Z_2$ 走向 0 相关。
  2. **协方差惩罚（Covariance Penalty）**：计算内积 $Loss_{cov} = [\sum(Z_1 - \bar{Z}_1)(Z_2 - \bar{Z}_2)]^2$。该计算仅涉及加减乘除与平方，计算速度极快且处处可导，能高效地在高维空间中实现特征的“正交化”。
- **模型意义**：通过这种强制解耦的表征学习，自编码器提取出的新特征将完全互斥，分别独立地解释数据中不同的规律（如单纯的价格敏感度 vs 纯粹的活动流量红利），为后续的深度时序预测模型（如 LSTM / Transformer）提供极其纯净、正交的输入信号。

## 6. 数据直觉的验证：为什么说 -0.674 的强相关性可能存在“欺骗性”？

虽然皮尔逊相关系数矩阵显示 `discount` 和 `activity_flag` 的相关性高达 -0.674，但在实际的业务数据场景中，这种纯粹的“线性强相关”其实是一种数学计算上的伪影（Artifact）。

### 6.1 统计学陷阱：点二列相关（Point-Biserial Correlation）
由于 `activity_flag` 是一个严格的二值变量（仅取 0 或 1），而 `discount` 是一个在某端（=1.0）具有极大方差偏态分布的连续变量，皮尔逊相关系数在此处实际上退化成了**“点二列相关”**。
它计算的并非我们常识中（如身高 vs 体重）的完美椭圆线性分布，而是衡量了：
- **$X=0$ 时，$Y$ 变量的均值高度（极度集中在 1.0）**
- **$X=1$ 时，$Y$ 变量的均值高度（散布在 0.5~0.9，均值较低）**
由于这两坨数据的均值落差极大，数学公式直接给出了 -0.674 的强线性相关评分。

### 6.2 散点图“奇怪”视觉表现背后的业务真相
仔细观察生成的带有 Jitter（抖动）处理的散点图，我们能发现它与教科书上的完美星云图截然不同，这恰恰反映了最真实的零售业务逻辑：

1. **粗柱状分布的真相**：
   二值分类特征导致数据在 X 轴的 0 和 1 处极端堆积，形成两根“粗柱子”。如果不施加抖动处理（Jitter），这 10 万个样本点将完全重叠为两条细线，掩盖其密度信息。

2. **Y 轴横向条纹的真相**：
   在 `activity_flag=1` 的右侧柱子中，Y 轴上的散点呈现出明显的横向条纹状聚集（如 0.5、0.8、0.9 处）。这说明在真实的生鲜业务中，折扣率不可能是连续的无理数，而是高度聚集在某些**人为设定的固定折扣档位**上。

3. **零点孤线的真相**：
   在 `activity_flag=0` 的左下角，存在一条孤零零贴着 X 轴（`discount=0.0`）的横线。这代表即便当天没有任何官方大促活动，系统内依然存在一部分“0元购”或“买一赠一的附赠品”订单。

**总结**：这些看似“奇怪”的散点图视觉表现，完美证明了生鲜数据呈现出的是一种强条件的**非线性 If-Then 逻辑分布**。因此，在建模时绝对不能盲目依赖 PCA 等线性降维手段，而必须采用能捕捉阶跃条件逻辑的**树模型（Tree-based Models）**，或运用深度学习表征解耦。
